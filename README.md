# Дублёр — сайт-визитка

Статический сайт без сборки: папку можно выложить на любой хостинг как есть.

| Файл | Зачем |
|---|---|
| `index.html`, `styles.css`, `app.js`, `boot.js` | сама страница |
| `404.html` | страница «не найдено», хостинги подхватывают её сами |
| `favicon.svg`, `favicon.ico`, `apple-touch-icon.png` | иконки для вкладки, закладок и iPhone |
| `fonts.css`, `fonts/` | шрифты сайта и их лицензии (SIL Open Font License) — сайт не зависит от Google |
| `og.png` | картинка-превью для Telegram, VK и соцсетей (1200×630) |
| `robots.txt` | разрешает индексацию |
| `_headers` | заголовки безопасности для Netlify и Cloudflare Pages |

## Перед публикацией

1. **Контакты** уже указаны в блоке «Пилот» в `index.html`: почта и Telegram.
2. **Домен для превью.** Когда появится адрес сайта, добавьте в `<head>` файла `index.html`
   после строки с `og:description` (вместо `ваш-домен` — настоящий адрес):

   ```html
   <meta property="og:url" content="https://ваш-домен/">
   <meta property="og:image" content="https://ваш-домен/og.png">
   <meta property="og:image:width" content="1200">
   <meta property="og:image:height" content="630">
   ```

   и замените `summary` на `summary_large_image` в строке `twitter:card`. Картинка `og.png` уже лежит
   в папке. Без абсолютного адреса Telegram и VK покажут ссылку без картинки.
3. **Заявки с формы.** По умолчанию форма открывает почтовый клиент с готовым письмом.
   Чтобы заявки приходили на почту без этого шага, заведите бесплатную форму на
   [Formspree](https://formspree.io) или [Web3Forms](https://web3forms.com) и вставьте её адрес
   в `FORM_ENDPOINT` в начале `app.js`.

## Где разместить

Зарубежные хостинги (Netlify, Vercel, Cloudflare Pages, GitHub Pages) из России в 2026 году
открываются нестабильно, а аудитория сайта — российские компании. Поэтому лучше российский хостинг.

### Яндекс Облако, Object Storage — почти бесплатно

1. Зайдите на console.yandex.cloud со своим Яндекс ID и создайте платёжный аккаунт (нужна карта).
   Хранение до 1 ГБ бесплатно, за трафик лендинга набегают копейки.
2. Object Storage → «Создать бакет»: имя латиницей (например, `dubler-site`),
   доступ на чтение объектов — «Публичный», класс хранилища — «Стандартное».
3. Откройте бакет → «Загрузить» → выберите все файлы этой папки, кроме `README.md` и `_headers`.
   Затем в бакете «Создать папку» → `fonts` и загрузите в неё всё содержимое папки `fonts/`.
4. В бакете раздел «Веб-сайт» → «Хостинг»: главная страница `index.html`, страница ошибки `404.html` → «Сохранить».
5. Адрес сайта появится там же, в настройках хостинга. Свой домен подключается позже, по инструкции Яндекса.

### Обычный российский хостинг — проще всего

Beget, Timeweb, Sprinthost и похожие, от 200–400 ₽ в месяц. После регистрации откройте
файловый менеджер в браузере и загрузите файлы этой папки вместе с папкой `fonts/` в корневую
папку сайта (обычно `public_html`). Удобнее загрузить zip-архив и распаковать его там же. Хостинг выдаст технический адрес с HTTPS, домен можно купить там же.

`_headers` — настройки безопасности только для Netlify и Cloudflare Pages, на российских хостингах он не нужен.
